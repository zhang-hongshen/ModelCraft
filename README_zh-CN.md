## ModelCraft 可以做什么

- **本地模型：** 在 Mac 上下载并运行模型。
- **多模态：** 文字、语音、图片、文档和音频。
- **项目：** 集中管理对话和文件。
- **Agent 工具：** 文件、命令、网页、Apple 应用和屏幕控制。
- **连接器：** 把 Mac 应用变成工具。
- **定时任务：** 按计划自动运行提示词。
- **媒体生成：** 图片、音频、音乐和视频。

## 开始使用

### 系统要求

- macOS 15 或更高版本

### 安装

- 从 [GitHub Releases](https://github.com/zhang-hongshen/ModelCraft/releases) 下载最新的 DMG。
- Homebrew：即将推出。
