## What ModelCraft does

- **Local models:** Download and run models on your Mac.
- **Multimodal:** Text, voice, images, documents, and audio.
- **Projects:** Keep chats and files together.
- **Agent tools:** Files, commands, web, Apple apps, and screen control.
- **Connectors:** Use your Mac apps as tools.
- **Scheduled tasks:** Run prompts on a schedule.
- **Media generation:** Images, audio, music, and video.
